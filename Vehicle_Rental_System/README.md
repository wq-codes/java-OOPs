Vehicle Rental System

A Java-based Vehicle Rental System built to practice and demonstrate core Object-Oriented Programming (OOP) concepts, including abstraction, inheritance, interfaces, polymorphism, encapsulation, and dependency injection.

The system uses a common abstract Vehicle class and an Insurable interface to create a flexible and extensible vehicle hierarchy.
